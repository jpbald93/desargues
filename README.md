# Desargues's theorem in Lean 4

A Lean 4 + Mathlib formalisation of **Desargues's theorem** (#87 on Freek Wiedijk's list of 100
theorems) in the projective plane `ℙ K (Fin 3 → K)` over an arbitrary field, together with its
converse, by a coordinate (bracket) certificate.

> Let `K` be a field. If two triangles `ABC` and `A'B'C'` of `ℙ²(K)` are in perspective from a point
> `O` (`O, A, A'` collinear, and likewise for `B, B'` and `C, C'`), their consecutive vertices are
> distinct and corresponding sides are distinct lines, then the three points `AB ∩ A'B'`,
> `BC ∩ B'C'` and `CA ∩ C'A'` are collinear.

The algebraic core is the identity `[PQR] = [abc]·[a'b'c']·[aa' bb' cc']` for the bracket
`[u v w] = u ⬝ᵥ v ⨯₃ w`, valid over every commutative ring and closed by `ring`.

**Status:** all statements proved, with no `sorry`. `gate.sh` checks 24 named declarations.

## Main statements

| Lean name | File:line | Statement |
|---|---|---|
| `Desargues.desargues_det_identity` | `Desargues/Basic.lean:34` | the bracket factorisation `[PQR] = [abc][a'b'c'][aa' bb' cc']` (any `CommRing`) |
| `Desargues.desargues_det` | `Desargues/Main.lean:33` | Desargues, determinant form: `o ≠ 0` and `[o a a'] = [o b b'] = [o c c'] = 0` ⇒ `[PQR] = 0` |
| `Desargues.desargues_mk` | `Desargues/Main.lean:59` | Desargues in `ℙ K (Fin 3 → K)` with `Projectivization.cross` and Mathlib's `IsCollinear` |
| `Desargues.desargues_converse_det` | `Desargues/Main.lean:88` | converse, determinant form (nondegenerate triangles) |
| `Desargues.desargues_converse_mk` | `Desargues/Main.lean:106` | converse in `ℙ²`: the lines `AA'`, `BB'`, `CC'` are collinear in the dual plane, i.e. concurrent |
| `Desargues.isCollinear_mk_of_br_eq_zero`, `br_eq_zero_of_isCollinear_mk` | `Desargues/Plane.lean:27`, `:59` | three projective points are collinear iff their bracket vanishes |
| `Desargues.exists_dotProduct_eq_zero_of_br_eq_zero` | `Desargues/Plane.lean:100` | collinear dual points are concurrent lines |
| `Desargues.ex_desargues`, `ex_nonvacuous`, … | `Desargues/Examples.lean:74`, `:41` | a concrete non-degenerate configuration over `ℚ` |

## Verification

`./gate.sh` builds the library and generates its own `#print axioms` queries for 19 named
declarations, fully qualified (every declaration cited in `SPIKE_REPORT.md`, plus every name
queried by the axiom scratch file `scratch/Ax.lean`). The queries are generated by the gate itself, not read
from a file in the repository.

The gate fails if any of the following is true:
- a source file (`Desargues/*.lean`, `Desargues.lean`) contains `sorry`, `admit`, `native_decide`, `axiom`, `#eval`, `run_cmd`, `initialize`, `IO`, `set_option`, `macro`/`elab`/`syntax`/`notation`/`infix`/`prefix`/`postfix`, `import Lean` or `open Lean`;
- the build fails;
- a named declaration is missing, or has an extra report;
- a named declaration depends on anything other than `propext`, `Classical.choice` and `Quot.sound`.

Output: `PASS (24 declarations, standard axioms only)`. Some of these are definitions, which may
use a subset of the three axioms.

`tests/tamper.sh` plants six kinds of fake proof in scratch copies (in `Desargues/Examples.lean`) and checks
that the gate rejects each one (a rejection must exit nonzero and print the expected `FAIL`
message). The real repository is never modified.

| Test | What it plants |
|---|---|
| sorry | a `sorry` |
| ax2line | an axiom split across two lines |
| evalfake | an `#eval` that prints a fake axiom report |
| macro | a custom macro that rewrites `#print axioms` |
| falsehyp | the hypothesis `o ≠ 0` dropped from `desargues_det` (false: with `o = 0` the perspectivity hypotheses are vacuous) |
| wrap | a genuine extra axiom with a long name, so the report wraps over several lines |

`tests/tamper.sh` needs a prior `lake build` (it reuses `.lake/build`); run the tests one at a time.

The Python scripts in `code/` check the mathematics independently with exact arithmetic: random
perspective configurations over `ℚ` with a non-perspective control (`check_desargues.py`), the
factorisation (`identity_check.py`, `master_identity.py`, `reduced_identity.py`), and exhaustive
search over `𝔽₅²` including degenerate cases (`exhaustive_f5.py`, `degenerate_f5.py`).
`scratch/Ax.lean` is the axiom query recorded during development. `SPIKE_REPORT.md` is the
development log (its prior-art section is superseded by the one below).

## Prior art

Desargues's theorem is formalised in at least five other systems: HOL Light (Harrison; a coordinate
bracket proof over `ℝ`, `DESARGUES_DIRECT`), Isabelle (AFP *Projective Geometry*, Bordg, synthetic),
Rocq/Coq (Magaud, Narboux and Schreck, from incidence axioms), Metamath and Mizar. In Lean, Mathlib
has no Desargues statement; the open, unmerged Mathlib PR
[#37456](https://github.com/leanprover-community/mathlib4/pull/37456) proves the *affine parallel*
form. As far as we know this is the first Lean proof of the **projective-plane** formulation; no
claim of a first Lean proof of Desargues's theorem in general is made.

## Build

```sh
curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh   # if Lean is not installed
lake exe cache get
lake build
./gate.sh
bash tests/tamper.sh
```

Toolchain: Lean `v4.33.1`, Mathlib `v4.33.1` (revision pinned in `lake-manifest.json`).
`gate.sh` never fetches: run `lake exe cache get` (or `lake build`) first so that the pinned
Mathlib checkout is present in `.lake/packages`.

## Note on how this was produced

The formal proofs, checking scripts and documentation were developed with the help of a
large-language-model AI assistant. The author directed the work, reviewed the statements, and is
responsible for the result. The Lean kernel checks every proof.
